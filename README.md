# 开心农场 · 牧场经营（QQ 农场式逐格点击版）

一个**纯前端、零依赖、零构建**的农场经营游戏。核心玩法是 **QQ 农场那种一块一块点**：
锄地 → 播种 → 浇水 / 除虫除草 → 收获，再往上叠加工厂、连锁分店、订单与邻居社交。

打开 `index.html` 即可玩（或部署到任意静态托管）。

---

## 一、玩法速览

| 模块 | 内容 |
|---|---|
| **农场** | 6×6 = 36 块地（初始 9 块，可逐级开垦）。地块状态机：`荒地 → 耕地 → 生长中 → 成熟 → 枯萎`。生长中受**水分**（干涸则停止生长）、**杂草**、**虫害**影响；成熟后 1 小时不收会枯萎 |
| **牧场** | 12 个栏位、12 种动物。喂食恢复心情、抚摸提升亲密度（产量最高 +50%），心情 < 25 会罢工 |
| **加工** | 10 座工厂、20 个配方，队列随等级变长、速度随等级提升，钻石可加急 |
| **分店** | 5 类终端店（萌宠馆 / 咖啡馆 / 烘焙坊 / 餐厅 / 精品店），可雇员工、搞装修、补货、做宣传 |
| **订单** | 订单板报酬远高于市场价，前期最快资金来源 |
| **邻居** | 帮忙（浇水除草，赚金币 + 友好度）或偷菜（有狗的农场会被抓，罚款 + 掉友好度） |
| **系统** | 6 种天气、4 季（当季作物 ×1.25，非当季 ×0.72）、每日任务、42 个成就、图鉴、离线收益（上限 12 小时） |

### 拓展玩法（第二轮新增）

| 模块 | 内容 |
|---|---|
| **果园** | 8 个树位（初始 2，可逐级开垦）、8 种果树。**一次种植、反复结果**：先经历首次成熟，之后每轮自动结果，收完进入下一轮周期；当季果树 ×1.25、非当季 ×0.72；钻石 3 可催熟 |
| **鱼塘** | 6 口塘（初始 2）、4 种鱼（鲤鱼 / 草鱼 / 三文鱼 / 虾）。投放鱼苗 → 成鱼 → 捕捞；**喂食可让本轮成熟时间 −30%**；产出的鱼可直接卖，也是「鲜鱼寿司」的原料 |
| **矿洞** | 5 级矿洞。派矿工下井，按时长产出矿石；**等级越高单次产量越多、耗时越短、稀有矿概率越高**（Lv.1 无宝石 → Lv.5 宝石权重 16 / 煤 24）；钻石 2 可加急 |
| **中央厨房** | 6 级、最多 6 个灶台，**11 道菜**（沙拉 / 三明治 / 披萨 / 汉堡 / 寿司 / 牛排 / 浓汤 / 松饼 / 华夫饼 / 圣代 / 庆典蛋糕）。菜品是利润最高的一档，也是高级订单的主要来源 |
| **宠物** | 4 只宠物（看门狗 / 橘猫 / 牧羊犬 / 鹦鹉）。用宠物饲料喂食攒亲密度，满 100 升一级，**加成随等级放大**（1 + (等级−1) × 0.4）：看门狗让偷菜被抓概率 −50%（实测 35.4% → 18.3%，Lv.10 → 6.5%）、橘猫作物产量 +8%、牧羊犬动物产出 +12%、鹦鹉订单报酬 +15% |

拓展内容同时并入主线：新增 **8 种水果 + 稻米 + 奶油 + 11 道菜 + 4 种矿物**共 24 个物品、**12 张拓展订单**、**10 个拓展成就**、**5 条拓展每日任务**，并在「更多」页增加拓展图鉴与拓展统计。

**操作**：点地块执行当前该做的动作；**长按 / 右键**地块打开详情（浇水、施肥、加速、复活、清理）。

## 二、技术说明

- 纯 HTML5 + 原生 ES5 JavaScript + CSS3，**没有构建步骤、没有运行时依赖**
- 存档：`localStorage`（键 `farm_game_save_v3`），带字段迁移（v2 存档自动补齐果园 / 鱼塘 / 矿洞 / 厨房 / 宠物，老进度不丢）、损坏自愈、导入导出、离线结算
- 移动端优先，桌面端居中显示

### 文件结构

```
farm-game/
├── index.html            页面骨架（顶栏 / 主视图 / 13 个底部导航）
├── css/style.css         全部样式（底部导航可横向滚动）
├── js/
│   ├── data.js           全部数值与内容（作物 16 / 动物 12 / 工厂 10 / 配方 20 / 分店 5 / 物品 72 …）
│   ├── expansion.js      【拓展】数据层：果树 8 / 鱼 4 / 矿物 4 / 菜品 11 / 宠物 4
│   │                     + 拓展物品 24 / 订单 12 / 成就 10 / 每日任务 5
│   ├── state.js          存档读写、v2→v3 迁移、背包、经验
│   ├── sim.js            核心模拟：地块状态机、牧场、加工、分店、订单、开垦（含宠物加成挂钩）
│   ├── systems.js        天气 / 季节 / 成就 / 每日任务 / 邻居（含拓展成就判定）
│   ├── assets.js         素材映射层 + 缺失素材的画布兜底（动物 7 种 / 矿石 2 种）
│   ├── views.js          8 个主页面的渲染（纯函数，返回 HTML）
│   ├── ui.js             事件委托、抽屉 / 弹窗 / 提示 / 新手引导（default 分支转发拓展动作）
│   ├── exp.js            【拓展】模拟层：果园 / 鱼塘 / 矿洞 / 厨房 / 宠物 + tick / 离线 / 成就
│   ├── exp_views.js      【拓展】5 个新视图 + 动作分发 + 「更多」页拓展图鉴
│   └── main.js           启动入口与主循环
└── assets/images/        真实素材（见下）
```

脚本加载顺序：`data → expansion → state → sim → systems → assets → views → ui → exp → exp_views → main`
（拓展数据必须在 `state.js` 之前加载，这样新物品才能被存档迁移识别。）

> **关于素材替换**：`js/assets.js` 里有一张 `MAP`（逻辑名 → 路径）。
> 想换任何一张图，把同名 PNG 放进 `assets/images/` 对应目录即可，**不用改任何逻辑代码**。
> 图片缺失时会自动回退到占位图，绝不会出现破图。
> 若要让画布生成的小鸡 / 绵羊 / 山羊 / 羊驼 / 看门狗 / 橘猫 / 牧羊犬改用真实 PNG，
> 把对应名字从 `assets.js` 的 `CRITTERS` 数组里删掉即可；铁矿 / 煤矿同理，删 `ORES` 数组。

## 四、部署到 GitHub Pages + 自定义域名

### 1. 建仓库并推送

```bash
cd farm-game
git init
git add -A
git commit -m "开心农场 首个版本"
git branch -M main
git remote add origin https://github.com/zhonglike/farm-game.git
git push -u origin main
```

> ⚠️ **注意**：本次开发环境（沙箱）**无法访问 github.com**（网络不通），
> 所以推送这一步需要在**你自己的电脑**上执行。仓库文件我已经全部准备好了。

### 2. 开启 GitHub Pages

仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录 `/ (root)` → Save。

### 3. 绑定自定义域名 `farm.zhonglike.tech`

**① 仓库里放 CNAME**

仓库根目录已有 `CNAME` 文件，内容只有一行：

```
farm.zhonglike.tech
```

**② 域名服务商加解析记录**（以阿里云 / 万网为例）

| 记录类型 | 主机记录 | 记录值 | TTL |
|---|---|---|---|
| **CNAME** | `farm` | `zhonglike.github.io` | 10 分钟 |

- 主机记录填 `farm`（不要带主域名），最终访问 `farm.zhonglike.tech`
- **不要**用 A 记录指向 IP，GitHub Pages 的 IP 会变
- 如果想让**根域名** `zhonglike.tech` 也能访问，需要额外加 4 条 A 记录指向
  `185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153`（或 ANAME/ALIAS）

**③ GitHub 上填域名**

Settings → Pages → **Custom domain** 填 `farm.zhonglike.tech` → Save，然后勾选 **Enforce HTTPS**。

> 阿里云若提示"域名未备案无法解析"，需先完成备案；`.tech` 域名在部分服务商需确认支持。
> HTTPS 证书由 GitHub 自动签发，勾选后通常 **10～30 分钟**生效，期间访问可能报证书错误，属正常现象。

**④ 验证**

```bash
dig farm.zhonglike.tech CNAME +short   # 应输出 zhonglike.github.io
curl -I https://farm.zhonglike.tech    # 应返回 200
```
